# 4G Clinical

> 4G Clinical builds randomization and trial supply management (RTSM) software for clinical
> trials. Its Prancer RTSM platform uses natural language processing to turn a written RTSM
> specification into a deployable randomization and supply system; 4C Supply handles clinical
> supply forecasting and scenario planning, and 4G DataHub delivers portfolio-level study data
> into sponsor analytics environments. Headquarters: Wellesley, Massachusetts, USA.

## Important note for agents

4G Clinical publishes **no public API contract**. There is no developer portal, no API
reference, no OpenAPI/AsyncAPI/GraphQL/MCP document, no `llms.txt` of the company's own, and
no `/.well-known/` discovery surface on any of its hosts. A production API host exists at
`https://api.4gclinical.com` (AWS API Gateway) but returns HTTP 403 `ForbiddenException` to
every anonymous request. API access is arranged inside a sponsor engagement. This file is
generated by API Evangelist from public material; it is not published by 4G Clinical.

## Products

- [Prancer RTSM](https://www.4gclinical.com/products/prancer-rtsm/): randomization, trial
  supply management and study oversight in one platform.
- [Prancer RTSM Inventory Platform](https://www.4gclinical.com/prancer-rtsm-inventory-platform):
  supply management for investigator-sponsored trials.
- [4C Supply](https://www.4gclinical.com/technology): clinical supply forecasting, scenario
  modelling and long-range planning.
- [4G DataHub](https://www.4gclinical.com/clinical-data-integrations-reporting): portfolio-level
  study data delivery with API-enabled access for sponsor systems, dashboards and reporting
  environments.
- [Enterprise Prancer Integrations](https://www.4gclinical.com/technology#Integrations):
  sponsor-level integration configuration reused across studies.
